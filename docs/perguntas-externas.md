# Perguntas para o RT e o MAPA

> Atualizado em 04/10/2026. O ViniCycle é um produto **nacional**: as perguntas valem para qualquer UF, e as
> respostas que variam por estado viram parâmetros por UF (P16).
> As questões fiscais foram para [FISCAL.md](FISCAL.md).

## Em aberto

1. **GLT** (Guia de Livre Trânsito, obrigatória para transportar vinho a granel: Lei 7.678/1988, art. 2º, §1º; Decreto 12.709/2025, art. 235; emissão pela Portaria SDA/MAPA 690/2022):
   - é exigida quando a cantina devolve ao cliente o vinho **a granel**? E no envio de **mosto** para outra cantina?
   - pode ser emitida para destinatário sem registro no MAPA, como um cliente "cigano"?

2. **Declaração anual de quem contrata a elaboração** ("vinho cigano", Portaria MAPA 615/2023, art. 4º): se o contratante tem estabelecimento registrado e o vinho pronto volta para o estoque dele, esse vinho entra na declaração dele como entrada (sem produção)? Até a resposta, o sistema lança como "outras entradas (retorno de terceiro)", numa linha própria (ciclo 10).
